This installs putio-sync, which downloads your Put.io files and keeps them in sync.

After it finishes, open Put.io Sync Web UI in Applications (or http://localhost:15432/) to finish setup. The setup code is in ~/Library/Logs/putio-sync.log.

Skip Start at login under Customize to run putio-sync daemon yourself. To remove it later: sudo /usr/local/share/putio-sync/uninstall.sh.

putio-sync is not affiliated with Put.io.
