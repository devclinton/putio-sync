# putio-sync

[putio-sync](https://github.com/devclinton/putio-sync) is an unofficial sync daemon for [Put.io](https://put.io/); it is not affiliated with Put.io.
It downloads finished Put.io transfers, sends .torrent and .magnet files from a watch folder to Put.io, and acts as a download client for Radarr and Sonarr.

On first start it prints a setup code in the app logs. Open the web UI and enter the code, or the Web UI Token if you set one, then choose `/downloads` as the download folder.
