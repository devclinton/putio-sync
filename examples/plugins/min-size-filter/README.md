# min-size-filter

A **filter**: skips videos smaller than **Smallest video (MB)** (50 by default), such as
`sample.mkv` or a trailer next to the film. Files the built-in rules already block or skip
stay that way, and other files keep the built-in decision.

Skipped files show in the sync's file list as "skipped by plugin min-size-filter" and are
never deleted from Put.io.
