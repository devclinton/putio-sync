# tv-folders

A **folder** rule: `Show.S01E02.1080p.mkv` is downloaded to `TV/Show/Season 01/` in the
download folder, wherever it sits on Put.io. Files without `SxxEyy` in their name keep
their Put.io folder. **TV folder** sets the first part (`TV` by default).

Use it with [`clean-names`](../clean-names/) for `TV/Show/Season 01/Show S01E02.mkv`.
Files Radarr or Sonarr asked for keep their folders.
