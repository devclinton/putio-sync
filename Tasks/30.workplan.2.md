# Task 2: Refactor OAuth Endpoint to Separate Package

## Objective
Extract OAuth functionality from putio-sync-cli into a new putio-sync-oauth crate that can be used by both CLI and API server.

## Current State
- OAuth login endpoint is implemented in putio-sync-cli
- CLI runs its own temporary HTTP server for OAuth callback
- No shared OAuth infrastructure for API server

## Changes Required

### 1. Create New Crate: putio-sync-oauth
- Create `putio-sync-oauth` directory and Cargo.toml
- Add to workspace in root Cargo.toml
- Set up basic library structure

### 2. Extract OAuth Core Logic
- Move OAuth flow logic from CLI to new crate
- Create `OAuthServer` struct for handling callback
- Implement OAuth token exchange
- Support both CLI and API server modes

### 3. OAuth Server Modes
- **Standalone Mode**: CLI runs temporary server (current behavior)
  - Start server on localhost
  - Handle callback
  - Shutdown after token received
- **Integrated Mode**: API server provides endpoint
  - Register OAuth routes in API server
  - Store token in config
  - Keep server running

### 4. Update CLI Login Command
- Use putio-sync-oauth crate
- Run in standalone mode
- Maintain current user experience

### 5. API Server Integration
- Add OAuth routes when API server is enabled
- Use integrated mode
- Handle token storage

### 6. Configuration
- Add OAuth client ID/secret to config
- Support custom redirect URLs
- Handle both modes in config

## API Design

```rust
// putio-sync-oauth/src/lib.rs
pub struct OAuthConfig {
    pub client_id: String,
    pub client_secret: String,
    pub redirect_url: String,
    pub port: u16,
}

pub enum OAuthMode {
    Standalone,  // CLI mode - temporary server
    Integrated,  // API server mode - persistent routes
}

pub struct OAuthServer {
    config: OAuthConfig,
    mode: OAuthMode,
}

impl OAuthServer {
    pub async fn start(&self) -> Result<String>; // Returns token
    pub fn get_auth_url(&self) -> String;
    pub async fn exchange_code(&self, code: &str) -> Result<String>;
}
```
