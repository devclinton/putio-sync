**Key Features**:

**Global Options**:
```rust
pub struct Cli {
    pub config: Option<PathBuf>,  // -c, --config
    pub verbose: u8,               // -v, --verbose (repeatable)
    pub quiet: bool,               // -q, --quiet
    pub command: Commands,
}
```

**Features**:
- `--config <PATH>` - Custom config file path
  - Short form: `-c`
  - Environment variable: `PUTIO_SYNC_CONFIG`
  - Default: `~/.putiosync/config.toml`
- `--verbose` - Increase logging verbosity
  - Short form: `-v`
  - Repeatable: `-v`, `-vv`, `-vvv`
  - Counts from 0 to 3+
- `--quiet` - Suppress all output except errors
  - Short form: `-q`
  - Conflicts with `--verbose`
- `--help` - Display help information
  - Short form: `-h`
  - Auto-generated by clap
- `--version` - Display version information
  - Short form: `-V`
  - Pulls from `Cargo.toml`

**Commands**:

1. **Login Command**:
   ```
   putio-sync login [OPTIONS]

   Options:
     -t, --token <TOKEN>    Put.io OAuth token
     --interactive          Prompt for token interactively
     --no-verify            Skip token verification
   ```

   Features:
   - Manual token entry via `--token`
   - Interactive prompt mode
   - Token verification (default: enabled)
   - Conflicts: `--token` and `--interactive` are mutually exclusive

2. **List Command**:
   ```
   putio-sync list [PATH] [OPTIONS]

   Arguments:
     [PATH]  Remote folder path or ID [default: root]

   Options:
     -i, --id <ID>           List folder by ID
     -r, --recursive         List recursively
     -l, --long              Long format with details
     -f, --filter <PATTERN>  Filter by name pattern
     -t, --type <TYPE>       Filter by type
     --min-size <SIZE>       Min file size filter
     --max-size <SIZE>       Max file size filter
     --sort <FIELD>          Sort by field
     --reverse               Reverse sort order
     -o, --output <FORMAT>   Output format [default: table]
   ```

   Features:
   - Optional path argument or `--id` for folder ID
   - Recursive listing support
   - Long format for detailed output
   - Name pattern filtering (glob)
   - Type filtering (file, folder, video, audio, image, archive)
   - Size filtering with human-readable units
   - Sorting by name, size, or date
   - Reverse sort option
   - Multiple output formats: table (default), json, csv, tree

**Testing**:

- Tests cover argument parsing, flag combinations, conflicts

**Key Features**:

**Verbosity Mapping**:
```rust
0 (default)  -> Level::WARN   // Important warnings only
1 (-v)       -> Level::INFO   // Normal informational messages
2 (-vv)      -> Level::DEBUG  // Detailed debugging info
3+ (-vvv)    -> Level::TRACE  // Very detailed trace info
--quiet      -> Level::ERROR  // Errors only, suppress all other output
```

**Logging Configuration**:
- Respects `RUST_LOG` environment variable (overrides CLI flags)
- Colored output support with intelligent detection:
  - Checks if stdout is a TTY
  - Respects `NO_COLOR` environment variable
  - Disables colors on dumb terminals (`TERM=dumb`)
- Clean output format:
  - Timestamp included
  - Log level displayed
  - Target module disabled (cleaner output)
  - Thread IDs disabled

**Implementation Details**:

**Terminal Detection**:
```rust
fn supports_color() -> bool {
    atty::is(atty::Stream::Stdout)
        && std::env::var("NO_COLOR").is_err()
        && std::env::var("TERM").as_deref() != Ok("dumb")
}
```
