# Task 6: Add Logging Configuration

## Objective
Add comprehensive logging configuration to allow users to control log levels, output destinations, and log file rotation.

## Current State
- Logging uses `tracing` crate
- Log level controlled by `RUST_LOG` environment variable
- No file logging support
- No configurable logging in config file

## Changes Required

### 1. Add Logging Config to Config File

```toml
[logging]
# Log level: trace, debug, info, warn, error
level = "info"

# Enable file logging
file_enabled = true

# Log file path (supports ~ expansion)
file_path = "~/.putiosync/logs/putio-sync.log"

# Maximum log file size before rotation (in MB)
max_file_size_mb = 10

# Number of rotated log files to keep
max_backups = 5

# Enable console logging
console_enabled = true

# Console output format: "compact", "pretty", "json"
console_format = "compact"

# Filter logs by module
# Examples: "putio_sync=debug,putio_sync_download=trace"
module_filters = []
```

### 2. Create Logging Module in putio-sync-core

```rust
// putio-sync-core/src/logging.rs

use tracing_subscriber::{
    fmt, layer::SubscriberExt, util::SubscriberInitExt, EnvFilter, Layer,
};
use tracing_appender::{non_blocking, rolling};

pub struct LoggingConfig {
    pub level: String,
    pub file_enabled: bool,
    pub file_path: PathBuf,
    pub max_file_size_mb: u64,
    pub max_backups: usize,
    pub console_enabled: bool,
    pub console_format: ConsoleFormat,
    pub module_filters: Vec<String>,
}

pub enum ConsoleFormat {
    Compact,
    Pretty,
    Json,
}

pub fn init_logging(config: &LoggingConfig) -> Result<()> {
    let mut layers = Vec::new();

    // Console layer
    if config.console_enabled {
        let console_layer = match config.console_format {
            ConsoleFormat::Compact => fmt::layer().compact(),
            ConsoleFormat::Pretty => fmt::layer().pretty(),
            ConsoleFormat::Json => fmt::layer().json(),
        };
        layers.push(console_layer);
    }

    // File layer with rotation
    if config.file_enabled {
        let file_appender = rolling::daily(
            config.file_path.parent().unwrap(),
            config.file_path.file_name().unwrap(),
        );
        let (non_blocking, _guard) = non_blocking(file_appender);
        let file_layer = fmt::layer()
            .with_writer(non_blocking)
            .with_ansi(false);
        layers.push(file_layer);
    }

    // Build filter
    let filter = build_filter(config)?;

    tracing_subscriber::registry()
        .with(filter)
        .with(layers)
        .init();

    Ok(())
}

fn build_filter(config: &LoggingConfig) -> Result<EnvFilter> {
    let mut filter = EnvFilter::new(&config.level);

    for module_filter in &config.module_filters {
        filter = filter.add_directive(module_filter.parse()?);
    }

    Ok(filter)
}
```

### 3. Add Config Model

```rust
// putio-sync-core/src/config.rs

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct LoggingConfig {
    #[serde(default = "default_log_level")]
    pub level: String,

    #[serde(default = "default_true")]
    pub file_enabled: bool,

    #[serde(default = "default_log_path")]
    pub file_path: PathBuf,

    #[serde(default = "default_max_file_size")]
    pub max_file_size_mb: u64,

    #[serde(default = "default_max_backups")]
    pub max_backups: usize,

    #[serde(default = "default_true")]
    pub console_enabled: bool,

    #[serde(default)]
    pub console_format: ConsoleFormat,

    #[serde(default)]
    pub module_filters: Vec<String>,
}

fn default_log_level() -> String { "info".to_string() }
fn default_true() -> bool { true }
fn default_log_path() -> PathBuf {
    Config::default_path()
        .unwrap()
        .parent()
        .unwrap()
        .join("logs/putio-sync.log")
}
fn default_max_file_size() -> u64 { 10 }
fn default_max_backups() -> usize { 5 }

#[derive(Debug, Clone, Serialize, Deserialize, Default)]
pub enum ConsoleFormat {
    #[default]
    Compact,
    Pretty,
    Json,
}
```
