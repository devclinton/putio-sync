### 3.2 Debian Package Build Script
**Feature**: Script to build .deb packages

**Build Script** (`packaging/debian/build-deb.sh`):
```bash
#!/bin/bash
set -e

VERSION="$1"
ARCH="$2"

# Build binary
cargo build --release --target="${ARCH}-unknown-linux-gnu"

# Create package structure
mkdir -p "build/putio-sync_${VERSION}_${ARCH}"
cp -r packaging/debian/DEBIAN "build/putio-sync_${VERSION}_${ARCH}/"
mkdir -p "build/putio-sync_${VERSION}_${ARCH}/usr/bin"
cp "target/${ARCH}-unknown-linux-gnu/release/putio-sync" \
   "build/putio-sync_${VERSION}_${ARCH}/usr/bin/"

# Build package
dpkg-deb --build "build/putio-sync_${VERSION}_${ARCH}"
```

```yaml
name: Build Debian Packages

on:
  release:
    types: [published]

jobs:
  build-deb:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        arch: [amd64, arm64]
    steps:
      - uses: actions/checkout@v3
      - name: Install dependencies
        run: |
          sudo apt-get update
          sudo apt-get install -y dpkg-dev build-essential
      - name: Build .deb package
        run: |
          bash packaging/debian/build-deb.sh ${{ github.ref_name }} ${{ matrix.arch }}
      - name: Upload .deb to release
        uses: actions/upload-release-asset@v1
        with:
          upload_url: ${{ github.event.release.upload_url }}
          asset_path: build/putio-sync_${{ github.ref_name }}_${{ matrix.arch }}.deb
          asset_name: putio-sync_${{ github.ref_name }}_${{ matrix.arch }}.deb
          asset_content_type: application/vnd.debian.binary-package
```

## Release Process
1. Update version in Cargo.toml
